ရုပ်ရှင်အရှည်ကြီးကို ၅ မိနစ်အပိုင်းတွေ ဖြတ်ပြီး၊ မြန်မာလို script ရေးပြီး၊ အသံ (Thiha / Nilar) နဲ့ စာတန်းထိုးပါ တစ်ခါတည်း ထုတ်ပေးတဲ့ app ပါ။

Cut long movies into 5-minute parts, write the Burmese script, add voice and subtitles — all in one app.

⬇️ APK ဒေါင်းလုဒ်လုပ်မယ် (Download)

တင်နည်း (How to install)

  1. APK ကို ဒေါင်းလုဒ်လုပ်ပါ။
  2. ဖိုင်ကို နှိပ်ပြီး Install လုပ်ပါ — "Unknown sources / Install unknown apps" ကို ခွင့်ပြုပေးပါ။
  3. အရင် version ရှိရင် uninstall လုပ်စရာ မလိုဘူး — အပေါ်က တန်းတင်လို့ရတယ်။
  4. Gmail နဲ့ Sign in လုပ်ပြီး၊ ကိုယ့် Gemini key ကို ထည့်ပါ။

v1.3.39 မှာ ဘာအသစ်ပါလဲ

  • ယောက်ျားပြောတဲ့ လိုင်းကို မိန်းကလေးအသံနဲ့ ဖတ်နေတာ ပြင်ပြီးပြီ — "ကျွန်တော်" ဆိုတဲ့ စကားပါတဲ့ လိုင်းကို [Man] လို့ မှန်မှန်တပ်ပြီ (အသံကို ပြန်ထုတ်ရုံပဲ၊ Script ပြန်ရေးစရာ မလိုဘူး)
