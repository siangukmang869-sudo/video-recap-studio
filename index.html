တင်နည်း (How to install)

  1. APK ကို ဒေါင်းလုဒ်လုပ်ပါ။
  2. ဖိုင်ကို နှိပ်ပြီး Install လုပ်ပါ — "Unknown sources / Install unknown apps" ကို ခွင့်ပြုပေးပါ။
  3. အရင် version ရှိရင် uninstall လုပ်စရာ မလိုဘူး — အပေါ်က တန်းတင်လို့ရတယ်။
  4. Gmail နဲ့ Sign in လုပ်ပြီး၊ ကိုယ့် Gemini key ကို ထည့်ပါ။
